# Detailed Countries
A simple web application for exploring countries of the world.

## Tech Stack
- Backend: .NET
- Frontend: Angular
- Database: MongoDB

## Used APIs
- Country data: [REST Countries](https://restcountries.com)
- Map data: [OpenStreetMap](https://www.openstreetmap.org)
- Weather data: [Open-Meteo](https://open-meteo.com)

## External data
- Country borders: [world.geo.json](https://github.com/johan/world.geo.json/tree/master)
